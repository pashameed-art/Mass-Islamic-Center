## ⚡ Quick Start (5 Steps)

### **1️⃣ Create GitHub Repo**
```
Go: https://github.com/new
Name: duas-app
Public: ✅
Create!
```

### **2️⃣ Get Repo URL**
```
Copy: https://github.com/YOUR-USERNAME/duas-app.git
```

### **3️⃣ Create Folder & Files**
```bash
mkdir duas-app
cd duas-app

# Copy these 2 files:
# - index.html
# - manifest.json
```

### **4️⃣ Push to GitHub**
```bash
git init
git add .
git commit -m "Initial commit"
git remote add origin https://github.com/YOUR-USERNAME/duas-app.git
git branch -M main
git push -u origin main
```

### **5️⃣ Enable GitHub Pages**
```
Settings → Pages → ✅ Live!
```

**Done! App at:** https://YOUR-USERNAME.github.io/duas-app/

## ✨ Why This Approach?

✅ **No Build Process** - Just push HTML  
✅ **No npm Needed** - Zero dependencies  
✅ **Faster Updates** - 1 minute vs 5 minutes  
✅ **Easy Customization** - Text editor sufficient  
✅ **Smaller File Size** - ~40KB total  
✅ **Direct Deployment** - No GitHub Actions needed  
✅ **Simpler Maintenance** - Single file to manage  
✅ **Complete Features** - All PWA capabilities

## 🔧 Tech Stack (Single HTML)

```
HTML:       Page structure
CSS:        Styling (inline in <style>)
JavaScript: App logic (inline in <script>)
PWA:        Offline support (Service Worker)
LocalStorage: Favorites & settings
No frameworks, no build tools, no complexity!
```

## 📋 File Contents Summary

### **index.html (complete app in 1 file):**
```html
<!DOCTYPE html>
<head>
  <!-- PWA config -->
  <!-- Styles (CSS) -->
</head>
<body>
  <!-- App HTML -->
  
  <!-- JavaScript (all logic) -->
  <script>
    // App logic
    // Dua data
    // Event handlers
    // Service Worker
  </script>
</body>
</html>
```

### **manifest.json (PWA config):**
```json
{
  "name": "தினசரி துஆ",
  "icons": [...],
  "start_url": "/duas-app/",
  "display": "standalone"
}
```
