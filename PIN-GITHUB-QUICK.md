# 🔐 PIN + GitHub - Quick Start

**5 Minutes Setup! Secure & Synced!**

---

## 🔐 PIN Setup (1 minute)

### **Enable Admin Mode**
```
1. Settings ⚙️
2. Admin Mode → Toggle ON
3. Admin button (👨‍💼) appears
```

### **Create PIN (First Time)**
```
1. Click: 👨‍💼 Admin
2. Modal: "Set your 6-digit Admin PIN"
3. Tap numbers: 1-2-3-4-5-6
4. Submit
5. "✅ Admin PIN set successfully!"
```

### **Access Admin (Next Time)**
```
1. Click: 👨‍💼 Admin
2. Modal: "Enter your 6-digit PIN"
3. Enter PIN: 1-2-3-4-5-6
4. Auto-submits at 6 digits
5. Access Admin Panel! ✅
```

---

## ☁️ GitHub Setup (4 minutes)

### **Get GitHub Token**

**Go to:** GitHub Settings
```
Steps:
1. Login to github.com
2. Settings (top right)
3. Developer settings
4. Personal access tokens
5. Generate new token
6. Name: "Duas Backup"
7. Select: repo (full access)
8. Generate & Copy (save safely!)
```

### **Add to App**

**In Admin Panel:**
```
Admin → Backup tab

Fields:
1. Repo: your-username/repo-name
   Example: shahul/duas-app

2. Token: paste your token
   Example: ghp_abc123xyz...

3. Click: "📤 Sync to GitHub"
   Status: ⏳ Syncing...
   Result: ✅ Synced successfully!
```

### **Verify Upload**

**Go to GitHub:**
```
Repository: github.com/your-username/repo-name
See: duas-backup-YYYY-MM-DD.json
Click: View file content
Confirm: Your duas are there! ✅
```
