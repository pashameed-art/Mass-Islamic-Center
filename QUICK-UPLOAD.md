# 🚀 GitHub Upload - 5 Commands Only

**அத்தனை விரைவான Upload Guide!**

---

## ⚡ 5 Commands = Live App

```bash
cd duas-app

git status

git add .

git commit -m "Premium v2.0 - Advanced features"

git push origin main
```

**That's it! ✅**

---

## 📋 Step-by-Step (Tamil)

### **Step 1: Terminal Open செய்யவும்**

Windows:
```
Start button → Type: cmd → Press Enter
```

Mac:
```
Command + Space → Type: terminal → Press Enter
```

Linux:
```
Terminal app open செய்யவும்
```

---

### **Step 2: Folder-க்கு போக வேண்டும்**

உங்க் duas-app folder-ற போகவும்:

```bash
cd duas-app
```

---

### **Step 3: Check செய்யவும்**

```bash
git status
```

**Output:**
```
modified: index.html ← Should show this
```

---

### **Step 4: Add செய்யவும்**

```bash
git add .
```

(Dot = all files)

---

### **Step 5: Commit செய்யவும்**

```bash
git commit -m "Premium v2.0"
```

---

### **Step 6: Push செய்யவும்**

```bash
git push origin main
```

---

## ✅ Done! Upload Complete!
