## 🚀 Enable Admin (1 minute)

## 💾 Backup Your Data (2 minutes)

### **Download Backup:**

```
1. Admin → Backup tab
2. Click: "📥 Download Backup"
3. File: duas-backup-2024-10-15.json
4. Saved to: Downloads folder
```

**Contains:**
- All your duas (including custom ones)
- Favorite duas
- Settings & preferences

### **Restore from Backup:**

```
1. Admin → Backup tab
2. Click: "📤 Upload Backup"
3. Select: Your .json file
4. Confirm
5. All data restored! ✅
```
